# Curriculum sources

## Learn French with Clémence (structural reference only)

URL: https://www.learnfrenchwithclemence.com/course-curriculum (reviewed 2026-10-24)

**What is publicly visible:** lesson *titles* only. There are 180 numbered "day" lessons (30 per level, A1–C2) and supplementary libraries (pronunciation, word comparisons, false friends, ~90 vocabulary themes, short stories, DELF/TEF/TCF Canada preparation).

**Limitations:**
- No lesson text, exercises or audio are visible, and the page does not say what is paid.
- Several lists are truncated in the page itself ("+16", "+90", "+75", …).
- Many items are unnamed placeholders ("Common Mistake #1", "Picture #1").
- C1 and C2 are thematic, with no grammar labels.

**How Frenchia uses it:** only as a reference for **topic sequencing and CEFR placement**. For example, A2 runs: passé composé (avoir → être) → imparfait → passé composé vs imparfait → object pronouns → futur simple → impératif. No text, exercises or materials are reproduced. All lesson content is original and generated by the local LLM through the review pipeline (see `architecture.md`).
